# Changelog

## v1.0.0 — 2026-11-09
First public release. Supports Illustrator 2026 (30.8.2) and Illustrator 2027 Beta (31.1) on Apple Silicon.

- Stops the Color panel from opening when you click the Fill/Stroke swatches, press `<`, or use the
  Appearance panel. It's hidden before the screen updates, then closed the official way.
- Hides the Color pop-out when the panel is docked as a collapsed icon.
- Window > Color, F6, menu commands and workspace switches are never touched.
- Install and uninstall packages. No settings, no logs, no network.
